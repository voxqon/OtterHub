# 公共上传接口

在系统设置的“公共接口”中生成密钥。密钥只在生成或轮换时显示一次，停用会撤销密钥。密钥管理接口仍要求管理员 Cookie 或现有 `API_TOKEN`，公共密钥只能用于上传，不能访问管理接口。请在可信服务端保存密钥并使用 HTTPS，不要将密钥放在浏览器、移动客户端或公开仓库中。

`POST /public/upload` 的请求体是文件原始字节，单文件最多 20 MiB，不支持分片或标签，上传的文件默认公开。必需的请求头：

| 请求头 | 内容 |
| --- | --- |
| `X-Otter-Timestamp` | 当前 Unix 秒，允许与服务器时间相差不超过 300 秒 |
| `X-Otter-Filename` | UTF-8 文件名的 URL 百分号编码，如 `encodeURIComponent`；最多 128 个字符，不得包含路径分隔符或控制字符 |
| `X-Otter-Content-SHA256` | 请求体 SHA-256 的小写十六进制 |
| `X-Otter-Signature` | 以生成的密钥字符串的 UTF-8 字节为密钥，对下面的签名文本计算 HMAC-SHA256，结果为小写十六进制 |

签名文本以下列五行用换行符 `\n` 连接，无末尾换行：

```text
POST
/public/upload
<X-Otter-Timestamp>
<X-Otter-Filename>
<X-Otter-Content-SHA256>
```

设置页提供完整 Node.js 20+ 示例。成功返回 `{"success":true,"data":{"key":"..."}}`。无密钥、签名错误或时间过期返回 401；文件名或摘要错误返回 400；超出大小限制返回 413；存储失败返回 500。客户端应检查 HTTP 状态；失败或超时后盲目重试可能产生重复文件。

时间窗口限制了签名有效期，但不是一次性防重放机制，同一签名在有效期内可以重复使用。Cloudflare KV 是最终一致的，密钥轮换或停用可能需要时间传播，旧密钥在部分地区可能暂时仍可使用。接口不提供限流；部署时应结合 Cloudflare 防火墙/限流规则限制滥用。
